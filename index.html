3. Featured Projects

Graduation project · Cybersecurity · Machine Learning

Malware Detection & Incident Response Web Application

GitHub

A Flask web application where a signed-in user uploads a Windows executable, the system extracts structural features from its PE header, and a Random Forest model classifies it as malware or benign. Every scan is stored as an incident the user can review.

  1. EXE upload
  2. →
  3. PE feature extraction
  4. →
  5. Random Forest prediction
  6. →
  7. Malware / Benign
  8. →
  9. Incident record in MySQL

What is implemented

  • User registration and login
  • EXE upload with static analysis using the pefile library
  • 19 header and section features per file
  • Random Forest classifier (scikit-learn) trained on a 19,611-sample dataset and saved with joblib
  • Scan records in MySQL: file name, date, size and verdict
  • Per-user incident history with status updates and deletion

How it is organised

  • api.py: Flask routes and MySQL access
  • extract_from_exe.py: one extractor per feature
  • train_model.py: loads or trains the model
  • Six HTML templates: login, register, home, checker, result, incidents

Academic prototype. Files are analysed statically and never executed.
